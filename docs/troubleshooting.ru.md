# Решение проблем

## CapsLock ничего не делает

1. Посмотри на иконку в трее: правый клик → первый пункт должен быть «Отключить
   переключение» (значит, включено).
2. Проверь системную горячую клавишу: Параметры → Время и язык → Ввод → Дополнительные
   параметры клавиатуры → Сочетания клавиш для языка ввода. Способ, выбранный в
   caps-switch, должен совпадать с назначенным в Windows (`Левый Alt+Shift` по умолчанию).
3. Другой хук может перехватывать CapsLock (PowerToys Keyboard Manager, скрипты
   AutoHotkey, утилиты производителей). Закрой их и повтори.
4. Список раскладок: если установлен один язык ввода, переключать нечего. Добавь второй.

## Работает в обычных окнах, но не в админских

Хук из процесса без прав администратора не получает ввод, когда в фокусе окно с более
высоким уровнем целостности (UIPI). Нужен автозапуск задачей Планировщика с наивысшими
правами:

```powershell
caps-switch.exe --install --elevated     # из консоли администратора
```

или переустанови через `setup.exe`, выбрав режим «С повышенными правами».

## Пропала иконка в трее

- После перезапуска Проводника иконка возвращается сама (`TaskbarCreated`).
- Если её нет сразу после входа — приложение повторяет попытку раз в секунду, пока
  Проводник не поднимется.
- Проверь скрытые значки (шеврон «^»): Windows по умолчанию прячет новые иконки.
- Убедись, что процесс жив: `Get-Process caps-switch`.

## При переключении появляется большая плашка / ощущается задержка

Выбран способ `Win+Space` — Windows рисует для него всплывающее окно выбора языка.
Выбери в трее `Alt+Shift` или `Ctrl+Shift`: они переключают без плашки.

## Shift+CapsLock не включает Caps

Включи в меню трея пункт «Shift+CapsLock — обычный Caps». Если он выключен, CapsLock
полностью отдан переключению языка.

## Две записи в автозагрузке / две иконки

Режимы `--install` (реестр) и `--install --elevated` (задача Планировщика)
взаимоисключающие. Почисти и поставь один:

```powershell
caps-switch.exe --uninstall
caps-switch.exe --install          # либо --install --elevated
```

## Предупреждение антивируса или SmartScreen

exe не подписан и ставит глобальный хук клавиатуры — эвристики могут ругаться.
Сверь SHA-256 скачанного файла с указанным в релизе или собери сам из исходников
(`cargo build --release`).

## Сбросить все настройки

```powershell
Remove-Item -Recurse "HKCU:\Software\caps-switch"
```

## Полное удаление

```powershell
# через установщик: Параметры → Приложения → Установленные приложения → caps-switch
# через скрипт
.\install.ps1 -Uninstall
# вручную
caps-switch.exe --uninstall
Remove-Item -Recurse "$env:LOCALAPPDATA\Programs\caps-switch"
```

`--uninstall` убирает автозапуск; ключ настроек удаляет деинсталлятор (или вручную,
см. выше).
