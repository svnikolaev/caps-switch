# Архитектура

caps-switch — однопроцессное приложение для Windows без внешних зависимостей.
Внутри: низкоуровневый хук клавиатуры, скрытое окно с иконкой в трее и маленькое
хранилище настроек.

## Модель процесса

```
main()
 ├─ чтение настроек (HKCU\Software\caps-switch)
 ├─ мьютекс единственного экземпляра (Local\caps-switch-singleton)
 └─ run_tray()
      ├─ скрытое top-level окно (WS_POPUP, без HWND_MESSAGE)
      ├─ Shell_NotifyIconW(NIM_ADD)
      ├─ SetWindowsHookExW(WH_KEYBOARD_LL)
      └─ цикл сообщений (GetMessage/DispatchMessage)
```

Окно специально **top-level**, а не message-only: message-only окна не получают
broadcast-сообщения, а `TaskbarCreated` (перезапуск Проводника) — именно broadcast.
По этому сообщению иконка добавляется заново. Если `NIM_ADD` не сработал при входе
(Проводник ещё не поднялся), раз в секунду срабатывает таймер и повторяет попытку.

## Обработка клавиш

`hook_proc` работает внутри цикла сообщений и обязан отвечать мгновенно: Windows
снимает хук, если колбэк превышает `LowLevelHooksTimeout`. В колбэке нет ввода-вывода,
аллокаций и блокировок.

```
CapsLock вниз
 ├─ переключение выключено   → пропускаем (штатный CapsLock)
 ├─ зажат Shift (опция вкл)  → пропускаем (штатный Caps)
 ├─ клавиша уже зажата       → автоповтор, глотаем без переключения
 └─ иначе                    → глотаем и отправляем сочетание смены языка
CapsLock вверх               → глотаем (чтобы Caps не включился)
```

Сочетание — `Alt+Shift`, `Ctrl+Shift` или `Win+Space` по выбранному режиму.
Модификатор, который пользователь уже физически держит, **не** инжектится — иначе
синтетический key-up «отпустил» бы его клавишу посреди ввода.

События, созданные самим приложением, помечены `LLKHF_INJECTED` — они пропускаются
как есть, поэтому рекурсии нет.

## Резервный путь

Если `SendInput` не сработал, приложение отправляет активному окну
`WM_INPUTLANGCHANGEREQUEST` со следующей раскладкой. Список раскладок берётся
относительно **потока активного окна** (`GetWindowThreadProcessId` +
`GetKeyboardLayout`), а не собственного потока.

Оба пути блокируются UIPI, если активное окно имеет более высокий уровень целостности
(админское), а caps-switch запущен без прав администратора. Лечится автозапуском
задачей Планировщика с наивысшими правами.

## Настройки

Хранятся для пользователя в `HKCU\Software\caps-switch` через Win32 Registry API
(`RegGetValueW` / `RegSetKeyValueW`) — без дочерних процессов `reg.exe`:

| Значение | Тип | Смысл |
|---|---|---|
| `Enabled` | DWORD | переключение включено/выключено |
| `ShiftCaps` | DWORD | Shift+CapsLock оставляет штатный Caps |
| `Mode` | SZ | `alt_shift` \| `ctrl_shift` \| `win_space` |
| `Language` | SZ | `auto` \| `ru` \| `en` |

Запись выполняется в фоновом потоке, чтобы меню не блокировало поток хука.

## Автозапуск

Два взаимоисключающих варианта, управляются `--install` / `--install --elevated`:

1. `HKCU\...\CurrentVersion\Run` — обычные права, старт без повышения.
2. Задача Планировщика `caps-switch`, триггер «при входе», «выполнять с наивысшими
   правами» — работает и в админских окнах, UAC при входе не спрашивает.

`--uninstall` удаляет оба.

## Обновления

«Проверить обновления» (и CLI `--check-updates`) запрашивают
`api.github.com/repos/svnikolaev/caps-switch/releases/latest`, сравнивают версии и при
наличии новой предлагают обновиться. Обновление: скачивается standalone exe во временную
папку, приложение выходит, временный cmd-скрипт заменяет файл и запускает его заново
(заменить работающий exe нельзя).

## Иконка в трее

Серый 3D-колпачок клавиши с вдавленной площадкой и двумя стрелками. Генерируется
`tools/make-icon.ps1` в `assets/icon.ico` (16–256 px, PNG-энтри), встраивается в exe
через `include_bytes!` и создаётся в рантайме через `CreateIconFromResourceEx`
(при ошибке — стандартная системная иконка).

## Локализация

`src/i18n.rs` содержит две статические таблицы строк (RU/EN). Язык определяется один
раз при старте: явная настройка (`ru`/`en`) или системный язык интерфейса
(`GetUserDefaultUILanguage`, primary language 0x19 = русский). Меню трея строится
заново при каждом открытии, поэтому смена языка применяется сразу.

## Сборка и упаковка

- `caps-switch.exe` — приложение, ~370 КБ, только системные DLL.
- `caps-switch-setup-<версия>.exe` — установщик Inno Setup (2,2 МБ) с явным выбором
  режима: «только для меня» (`%LOCALAPPDATA%\Programs`, автозапуск в HKCU) или
  «для всех пользователей» (`Program Files`, автозапуск в HKLM, нужен UAC).
- `install.ps1` / `install.cmd` — установка скриптом из последнего релиза.
